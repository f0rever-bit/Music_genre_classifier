# План: Покращити observability та retry для BackgroundTask аналізу

## Що робимо

### 1. `backend/app/services/audio_analyzer.py` — Логування + захист файлу при помилці

**Додати logging на ключових кроках `run_analysis()`:**
- На старті: `logger.info("run_analysis: starting for music_id=%s")`
- Після встановлення статусу `analyzing`
- Перед `analyzer.analyze()`: лог resolve local_path
- Після успішного аналізу (вже є на рядку 108, залишити)

**Додати перевірку `file_path is None` перед аналізом:**
- Якщо `music.file_path` is None (файл був purged), одразу записати помилку в `analysis_error` замість crash в `get_storage().get_local_path()` і повернути False

**Прибрати `_purge_local_file` з except блоку (рядок 123):**
- Зараз при помилці аналізу файл все одно видаляється, що робить retry неможливим
- Залишити purge тільки при успішному аналізі (рядок 112)
